# Style Rules

1. Avoid generic ai design such as too many rounded corners
2. Overuse of gradients
3. Make the layout design as independent as possible from the logic of the app and as loosely coupled as possible from other layout components. The idea is that if we decide to change the style, or design we can easily do so without uprooting the whole project.
4. Don't use pastel colors

# Rules

1. Don't put yourself in the commits.
2. Don't overengineer

# Workflow
Usually the workflow that you will be asked to do is the following: See which of the tasks are available to work on (has dependencies satisfied) and work on it, then when it is done repeat the process to work on the next task and so on for a specified number of tasks provided by the user.
